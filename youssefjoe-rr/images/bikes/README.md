# إزاي ترفع صور البايكات (من الموبايل)

1. سمّي كل صورة باسم **كود البايك - رقم الصورة**:
   - بايك كود 52 → `52-1.jpg` ، `52-2.jpg` ، `52-3.jpg`
   - الصورة رقم 1 هي اللي بتظهر على الكارت، فخليها أحلى صورة.
2. افتح الريبو على GitHub من المتصفح ← ادخل على الفولدر ده `youssefjoe-rr/images/bikes`
3. اضغط **Add file ← Upload files** واختار الصور.
4. اضغط **Commit changes**. الموقع هيعرض الصور لوحده خلال دقيقة.

- الصيغ المقبولة: jpg / jpeg / png / webp
- أقصى عدد: 8 صور لكل بايك
- لو مفيش صور، الموقع بيعرض شكل افتراضي فيه اسم البايك.

## تعديل البايكات أو الأسعار
كل البايكات في ملف `youssefjoe-rr/bikes.js`.
- بايك اتباع؟ غيّر `status: "available"` لـ `status: "sold"` (أو امسح السطر كله).
- بايك محجوز؟ خليها `status: "reserved"`.
